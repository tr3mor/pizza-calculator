# Pizza Calculator

A dough calculator for artisan pizza, based on baker's percentages. Enter your doughball weight, count, and hydration, and get a full recipe with poolish and main dough breakdowns.

**Live app: https://tr3mor.github.io/pizza-calculator/**

## Recipes

- **Neapolitan** — classic poolish-based dough
- **New York** — poolish-based dough with adjusted hydration and proof time

## Development

```bash
npm install
npm run dev      # start dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
```

Built with [Vue 3](https://vuejs.org/) and [Vite](https://vitejs.dev/). Deploys to GitHub Pages automatically on push to `main` via GitHub Actions.
